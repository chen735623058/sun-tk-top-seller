# 🐾 TikTok Shop Pet Title Optimizer

TK美区宠物用品标题智能优化工具 - 内置200+ 2026年最新热门搜索关键词，自动匹配生成优化标题，提升搜索曝光！

## ✨ 功能特点

- 🎯 **智能关键词匹配** - 根据你的商品自动从200+热门关键词库中匹配相关关键词
- 📝 **多种风格生成** - 生成5个不同风格标题：1个基础标准款 + 2个长尾精准款 + 2个营销吸引款
- 📱 **响应式设计** - 漂亮的网页界面，手机电脑都能用，一键复制标题
- 🔧 **关键词管理** - 支持随时添加新的热门关键词，自动保存
- 📊 **符合TK规则** - 标题长度控制在合理范围，核心关键词前置，符合美区搜索习惯

## 🎨 使用方法

1. 在顶部输入你的商品英文名称（例如 `Automatic Cat Litter Box`）
2. 可以补充填写商品描述
3. 点击「生成优化标题」按钮
4. 系统会自动匹配相关热门关键词，生成5个优化标题
5. 点击 `Copy` 按钮直接复制使用

## 🔧 添加新关键词

在页面底部「关键词库管理」区域：
1. 选择分类
2. 输入新关键词
3. 点击 `Add` 即可添加，系统自动保存

## 📖 生成规则

- 尽可能多包含热门搜索关键词，提升搜索曝光
- 核心大词放前面，长尾词放后面，符合美区消费者搜索习惯
- 自动加入热门转化属性词：`premium`, `durable`, `easy to clean`, `non toxic` 等
- 标题长度控制合理，符合TikTok Shop搜索排名规则
